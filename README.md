# ばくだん暴露

おうち飲み会用のゲームです。テレビにつないだパソコンでゲームを進行し、参加者は各自のスマホから遊びます。

- 構成:GitHub Pages(画面)+ Firebase Realtime Database(端末どうしの通信)+ Firebase 匿名認証
- 参加人数:3〜11人程度
- 記録:質問と答えは、テレビの画面を閉じると部屋ごと消えます。

## ファイル

| ファイル | 内容 |
|---|---|
| `index.html` | 入口(テレビで部屋を作る/スマホで参加する) |
| `tv.html` + `js/tv.js` | テレビ画面。ゲームの進行役で、状態はすべてここで持ちます |
| `phone.html` + `js/phone.js` | スマホ画面 |
| `js/shared.js` | カード・質問・絵柄・性格診断など、両方で使うデータ |
| `js/net.js` | 通信部分(Firebase/試験モード) |
| `js/config.js` | Firebase の設定値を書くファイル |
| `database.rules.json` | Realtime Database のセキュリティルール |
| `css/style.css` | 見た目 |

## まず試験モードで試す(Firebase の設定は不要)

`js/config.js` の `apiKey` が空のあいだは、1台のパソコンの中だけで動く試験モードになります。

1. このフォルダで `python -m http.server 8000` を実行します(または GitHub Pages に置きます)。
2. ブラウザで `http://localhost:8000/tv.html` を開きます。
3. 同じブラウザの別のタブで `http://localhost:8000/phone.html` を3つ以上開き、テレビに出ている部屋コードで参加します。

※ ファイルをダブルクリックして開く方法(`file://`)では動きません。

## 本番の準備

### 1. Firebase プロジェクトを用意する

「ひみつのギフト」と同じプロジェクトを使っても、新しく作ってもかまいません。

1. Firebase コンソールでプロジェクトを開きます。
2. 「Authentication」→「Sign-in method」で「匿名」を有効にします。
3. 「Authentication」→「設定」→「承認済みドメイン」に、GitHub Pages のドメイン(例:`ユーザー名.github.io`)を追加します。
4. 「Realtime Database」を作成します。場所はシンガポール(asia-southeast1)を選びます。
5. 「Realtime Database」→「ルール」に `database.rules.json` の中身を貼り付けて公開します。

### 2. 設定値を書く

1. 「プロジェクトの設定」→「マイアプリ」でウェブアプリを登録します(登録済みならそれを使います)。
2. 表示された `firebaseConfig` の値を `js/config.js` に貼り付けます。`databaseURL` が入っていることを確認してください。

### 3. GitHub Pages で公開する

1. このフォルダの中身をリポジトリに置きます。
2. リポジトリの「Settings」→「Pages」で、公開するブランチを選びます。
3. 表示されたアドレスの `tv.html` をテレビ側のパソコンで開きます。

## 当日の流れ

1. テレビ側のパソコンで `tv.html` を開き、「全画面」を押します。
2. 参加者はテレビの QR コードを読み、名前を入れて参加します。
3. 最初に参加した人が「幹事」になり、スマホからも開始や「次へ」の操作ができます。
4. テレビの画面で過激度・カード・ラウンド数・導火線の長さを選び、「はじめる」を押します。
5. 終わったら「性格診断を見る」で、全員のプレイスタイルがテレビに、詳しい解説が各自のスマホに出ます。
6. 最後に「部屋を閉じる」を押すと、質問と答えを含む部屋のデータが消えます。テレビの画面を閉じた場合も消えます。

## 知っておいてほしいこと

- 持っている人の通信が15秒切れると、爆弾は自動で別の人へ移ります。
- ゲームの途中で参加した人は、次に待合へ戻ったときから参加できます。
- テレビ側のパソコンがスリープすると、部屋が消えます。スリープしない設定にしてください。
